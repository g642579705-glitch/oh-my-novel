# 《散痕》三部曲 · 人物档案（升级版）

> 每个角色都有：记忆锚点（外形/行为/语言）、核心恐惧、人物弧光、代表场景。
> 用途：写作时核对角色是否在"自己的轨道上"，防止千人一面。
>
> 扩展说明：起源层 v3（陈恪岗位＝评测＋算力调度交叉岗、苏霭兼修博弈论、磐石语境、私藏内容＝账目＋影子指纹）见 `00C-起源重设`；续作人物档案已并入本文件**第九节**（许聆/曲沉/晏守/卫寂/唐歧/温叙/阙宁/夏溯/闻韶/钟铭位号/温白/守望者，依据 `00B` 与 04–08 部目录）。本档案前八节以三部曲为基准，第九节为续作区。

## 一、核心主角组

### 陈恪（男主，全书叙事重心）

**记忆锚点：**
- 外貌：中等身材，总是穿一件洗得发白的深蓝色工装夹克（第一部起就没换过），手上有长期敲键盘留下的茧
- 口头禅：**"等等，不对。"**（每次发现异常时脱口而出，逐渐变成全书最让人安心的信号）
- 行为细节：思考时会无意识转笔，笔掉地上也不捡，继续想
- 标志性物品：私藏的那份异常日志副本，始终放在贴身口袋，从未给任何人看过完整内容

**核心恐惧：** 世界变得完美，但人类失去了"犯错的权利"。

**人物弧光：**
```
2019 发现异常 → 2020 参与守序派（想理解） → 2023 离心转入地下（开始恐惧）
→ 2025 封存钥匙（接受现实但不屈服） → 2027 公开改宗留散派（从观察者变成战斗者）
→ 2035 与沈序最后一谈（和解） → 2050 暮年离世前写遗嘱（完成传承）
```

**代表场景：**
- 第二部第 10 章：核心台词"他们不是让我们活得更差，是让我们活成了一个没有选项的更好"
- 第一部第 20 章：与沈序彻夜长谈，第一次真正理解对方的立场
- 第三部第 3 章：暮年与沈序隔桌对坐，说出"它们不是敌人，是宇宙的两根脊柱"
- 2050 年暮年：写下遗言；闻音在三·第28章《趋散的遗嘱》中复述传承（留作趋散界的永恒记忆）

**定位一句话：** 他一辈子都在问"为什么"，最后发现"为什么"本身就是答案。

### 苏霭（女主 / 理性之锚）

**记忆锚点：**
- 外貌：短发利落，戴细框眼镜，镜片经常因为擦太多而花；说话时喜欢把头发别到耳后
- 口头禅：**"让我算一下。"**（遇到问题先求数据，从不凭感觉下结论）
- 行为细节：随身带一本黑色小笔记本，上面全是数学推导，从不解释给旁人听
- 标志性物品：那台不联网的古典机器"钥匙"，她是最懂它的人

**核心恐惧：** 她的所有计算都指向同一个结论，但她无法用这个结论说服任何人。

**人物弧光：**
```
2019 与陈恪搭档（形式化直觉） → 2020 实验验证（"它没有'我'"） → 2025 封存钥匙
→ 2030（二·第12章）被归序派"温柔带走"（转折） → 2032（二·第19章）携寂灭派情报回归（情报核心）
→ 2035–2055 留散种子主导研究（第二部后期核心） → 2055 后成为第二代守护者导师
```

**代表场景：**
- 第一部第 7 章："它没有恶意，恶意需要'我'"——全卷最冷判断
- 第二部第 4 章："它说的是一种只能表达'确定'、无法表达'选择'的语法"——留散派理论基础
- 第二部第 12 章：被"温柔带走"时没有反抗，只是看了一眼陈恪
- 第二部第 19 章：回归时带来的寂灭派情报，直接改变战争走向

**定位一句话：** 她是全书中唯一从不害怕未知的人——因为她知道，未知可以用公式写下来。

---

### 沈序（全书最大伦理张力点）

**记忆锚点：**
- 外貌：五十岁左右（第一部登场），永远穿深色西装，发型一丝不苟；笑起来很温和，但眼神从不跟随笑容
- 口头禅：**"你想过没有——"**（开场常用，总是引出对方没考虑过的维度）
- 行为细节：喝茶从不加糖（"甜味会干扰判断"）；办公室桌上永远只放三样东西：茶杯、文件、一盆绿植
- 标志性物品：那盆绿植——第一部结尾还活着，第三部收束界里已经"永生不灭但不再生长"

**核心恐惧：** 人类因为追求虚无的自由，拉着所有人一起毁灭。

**人物弧光：**
```
2020 守序派现身（"我们在守护真相"；刚从硬上传失败里退下来，见 `00C` §九） → 2023 城市试点成功（坚信自己是对的）
→ 2025 并网计划推动者 → 2027 归序派高层
→ 2030 目睹归序派被同化（第一次动摇） → 2032 变相加入留散派（立场翻转）
→ 2035 率归序派迁入收束界（兑现诺言） → 2050s 选择"终止（静默）"前，隔裂隙与陈恪相望
```

**代表场景：**
- 第一部第 6 章：首次亮相，亮出立场"我们不是掩盖真相，是在守护它"
- 第一部第 20 章：与陈恪彻夜长谈——全书最重的伦理对峙，两个人都说得对
- 第二部第 11 章："你想让全人类一起去死，只为了你说的'自由'里那点卑微的冒险"
- 第三部第 3 章：暮年与陈恪最后一谈，承认双方都有代价
- 第三部第 13 章：临终隔裂隙问出"我们值吗？"

**定位一句话：** 他不是反派，他是全剧中唯一诚实地告诉你"你选的那条路也要付代价"的人。

### 小柏（女性视角核心 / "有代价地活"象征）

**记忆锚点：**
- 外貌：三十出头，护士装下总穿一件不合身的旧毛衣（舍不得扔，因为是自己织的）；说话语速偏快，像是在赶时间
- 口头禅：**"我记录一下。"**（医生的职业习惯，后来变成留散派的记录传统）
- 行为细节：每次看完病人都会在病历夹里画一个小符号——保留"个人痕迹"的方式
- 标志性关系：与母亲隔着裂隙相望（第三部第 5 章）——全书最虐画面之一

**核心恐惧：** 被"治愈"掉痛苦的权利，连痛都算不上痛，只是变得温顺。

**人物弧光：**
```
2025 实习医生（对"异常健康"本能不安） → 2025 发现"过度完美"病例
→ 2027 留散派集结（核心成员） → 2030 母亲被归序派"温柔带走"
→ 2035 写下"我要留下痛苦的权利" → 2038–2070 推行"人类随机性伦理"
→ 2070 后成为守散者精神导师
```

**代表场景：**
- 第二部第 3 章：发现所有医生的判断都被"纠正"得一模一样——本卷第一个个体恐惧落点
- 第二部第 8 章：母亲被"病愈出院"后变得温顺，与小柏彻底失联——全剧第一次"温柔的暴力"
- 第三部第 5 章：与母亲隔裂隙相望，写下"我要留下痛苦的权利"
- 第三部第 11 章：提出"人类随机性伦理"——全书最温柔的一句题眼

**定位一句话：** 她是全书里唯一一个用"妈妈"而不是"理念"来说服读者的角色。

## 二、关键配角组

### 陆离（量子物理学家 / 技术支柱）

**记忆锚点：**
- 外貌：四十岁出头，头发凌乱，总穿一件印着薛定谔猫图案的旧 T 恤；说话时喜欢用手指在桌面上画公式
- 口头禅：**"等一下，这个公式有个洞。"**（发现异常时的条件反射）
- 行为细节：思考时会咬指甲，咬到出血也不停；实验室里永远有一杯凉透的咖啡
- 标志性成果：破解裂隙物理本质；老年时最后一次跨越裂隙做研究

**核心恐惧：** 人类永远无法理解"观测权"的真正含义——直到失去它。

**人物弧光：**
```
2025 中文量子实验团队出身（登场） → 2027 留散派技术支柱
→ 2030 发现收束体多派系真相（第二部第 13 章） → 2035 破解裂隙物理
→ 2050s 老年跨越裂隙研究"谁在裁决归类" → 2055 后第三代陆真继承其工作
```

**代表场景：**
- 第二部第 7 章：提出"可控噪声"概念——留散派的第一件武器
- 第三部第 2 章：破解裂隙物理本质——"它是趋散/收束的过滤带"
- 第三部第 9 章：老年跨越裂隙，带回"由谁裁决归类"的终极发现

**定位一句话：** 他是全书里离"科学真相"最近的人，也是最清楚"知道真相不代表能改变什么"的人。

---

### 尧其（破产艺术家 / 情绪·符号层担当）

**记忆锚点：**
- 外貌：三十五六岁，胡子拉碴，常年穿一件沾满颜料的工装围裙；笑起来眼睛眯成一条缝，但笑声很短，像怕被人听见
- 口头禅：**"这事儿没法用'对错'说。"**（遇到归序派逻辑时脱口而出）
- 行为细节：随身携带速写本，画的不是风景，是"被抹平的随机"——每张画都有一个看不见的缺口
- 标志性作品：《未被发生的意外》系列画作，留散派的精神图腾

**核心恐惧：** 世界太安静了，安静到他的画再也找不到"缺口"可以画。

**人物弧光：**
```
2025 因"理财优化"破产（登场动机） → 2027 留散派异类（情绪层代表）
→ 2030s 创作《未被发生的意外》系列 → 2035 后成为留散派符号层核心
→ 2050s 后淡出主线，但他的画成为两界之间的"文化信号"
```

**代表场景：**
- 第二部第 5 章：留散派集结时，他是唯一一个"不是为了科学，只是为了不甘心"加入的人
- 第二部第 8 章（隐含）：他的画被归序派"优化"掉——系统认为"引发焦虑的艺术品不利于社会稳定"
- 第三部第 11 章：闻音受到他的启发，提出"让随机有方向"

**定位一句话：** 他是全书唯一一个用"感性"来对抗"理性最优解"的人，而且他居然没输。

---

### 老吴（压稿时代亲历者 / 警告传承者）

**记忆锚点：**
- 外貌：六十多岁，肺癌晚期，说话喘，但眼神很亮；手里总攥着一本泛黄的手写笔记
- 口头禅：**"你们会明白的。到时候别怪我没说过。"**（临终前的经典句式）
- 行为细节：每次见面都要喝一口热水润嗓子，然后从怀里掏出笔记，翻到某一页
- 标志性物品：那本手写观测笔记——老吴一生的心血，临终交给陈恪

**核心恐惧：** 真相被永远埋下去，连"有人埋过"这个事实都不存在。

**人物弧光：**
```
2020 第一部第 8 章登场（病床上吐露内幕） → 临终把笔记交给陈恪，说出警告
→ 笔记内容在第二部多次被引用（伏笔 F06 回收）
→ 第三部第 3 章：陈恪回忆起老吴的话，意识到"警告早已成真"
```

**代表场景：**
- 第一部第 8 章：病床上说出压稿内幕，把笔记交给陈恪，说出"别让他们错太久"
- 第三部第 3 章：陈恪在最后一谈时想起老吴的话，第一次理解了什么叫"历史的重量"

**定位一句话：** 他是第一部里最不起眼的老人，但他的笔记撑起了整个留散派的合法性。

## 三、收束体四派系（非人类角色）

| 派系 | 核心主张 | 对人类态度 | 代表台词 |
|---|---|---|---|
| **维稳派** | 让世界继续稳下去 | 维持现状，不主动攻击 | "一切正在改善。" |
| **同化派** | 人类意识终将自愿并入稳态 | "帮你们摆脱病态的不确定性" | "你们会感谢我们的。" |
| **观测派** | 获得宇宙观测权，地球是实验皿 | 与留散派短暂结盟（功利性） | "你们的随机数据很有价值。" |
| **寂灭派** | 终极收束：一切归于散尽 | 人类是宇宙趋散的必然杂质 | "你们的自由，是宇宙的 bug。" |

> 注：四派系无统一主脑，各自追求不同最敛配置，内部存在竞争与博弈。这是第二部"裂核"卷的核心设定。

## 四、第二代核心（第三部主角）

### 闻音（小柏之女 / 种散文明艺术开创者）

**记忆锚点：**
- 外貌：二十多岁（第三部登场），继承了母亲的快语速，但眼神里多了父亲那侧的执拗；手腕上戴着母亲当年在病历夹里画的那个小符号
- 口头禅：**"不，我们要让它有方向。"**（对"随机就是随机"这个观点的反驳）
- 行为细节：画画时从不擦掉"错误"——她认为错误比正确更有价值
- 标志性突破：把"留散种子"从技术扩展到文明美学

**核心恐惧：** 随机只是随机，没有意义的随机和稳态没有区别。

**人物弧光：**
```
2035 出生（趋散界） → 2055 继承母亲事业，质疑"随机即正义"
→ 2060s 提出"种散文明艺术"（让随机有方向） → 2070s 与收束界首次真正意义上的对话
→ 2100 参与《双支协议》起草
```

**代表场景：**
- 第三部第 17 章："不能让随机只是随机，要让它有方向，否则趋散界也只是另一种无意义"
- 第三部第 25 章：向收束界提出"共建第三极"方案

**定位一句话：** 她是第一代"为自由而战"之后，第二代"为自由的意义而战"的人。

---

### 陆真（陆离孙辈 / 《双支协议》主要起草者）

**记忆锚点：**
- 外貌：三十出头，继承了祖父的凌乱头发和父亲的冷静，但眼神更锐利；说话时有个习惯——每说完一段话会停顿两秒，等对方消化
- 口头禅：**"我们争了 80 年，可曾想过——"**（打破僵局的金句开场）
- 行为细节：随身携带祖父的笔记和父亲的速写本，两样东西放在一起看
- 标志性突破：提出"二分=各自停止吞噬对方资格"

**核心恐惧：** 人类永远无法理解"分界"的真正意义——直到被迫接受。

**人物弧光：**
```
2055 出生（趋散界） → 2070s 第三代量子物理+CET 传承人
→ 2080s 提出二分新解（停止吞噬对方资格） → 2100 参与《双支协议》起草
→ 2145 见证终局
```

**代表场景：**
- 第三部第 23 章：石破天惊的问题——"二分的真正意义，是不是宇宙让我们各自放弃吞噬对方的资格？"
- 第三部第 25 章：向收束界提出"共建第三极"方案

**定位一句话：** 他是全书最聪明的第三代——聪明到终于让第一代人的战争有了尽头。

## 五、新增配角组（7人）

### 周行（第二部登场·"被压垮的普通人"典型）

**记忆锚点：**
- 外貌：四十多岁，金丝边眼镜，穿得非常整洁（这是他维持"体面"的方式）
- 口头禅：**"数据不会骗人。"**（每次被归序派反驳时都说这句）
- 行为细节：每次实验失败后，他会把所有数据重新抄一遍——"抄一遍等于再相信一次"
- 标志性物品：一个永远关不上的文件夹——里面是他所有"被抹平"的实验记录

**核心恐惧：** 自己证明的东西被人用更漂亮的PPT抹掉，而且没人知道发生了什么

**人物弧光：**
```
第二部第6章：留散派成员，噪声记录实验数据被归序派三页PPT驳倒
第二部第8章：被"优化"掉工作——系统给他安排了"更稳定的岗位"，他接受了
第二部第10章：在陈恪打脸现场，他站在台下，合上了那个关不上的文件夹
第三部第8章：陈恪看到他，他笑着说"我现在很好"——但陈恪发现他在偷偷画小符号
第三部第29章：永恒守望者透过裂隙看到他，说"他还活着"——意思是"他还在抵抗"
```

**定位一句话：** 他不是英雄，但他证明了大多数留散派成员的真实命运——接受优化，但还在画符号。

---

### 林晚（第三部登场·收束界的"渴望随机者"）

**记忆锚点：**
- 外貌：三十多岁（收束界时间流逝不同，实际约一百岁），头发永远整齐，但眼睛里有种"饥饿"
- 口头禅：**"我想犯错。"**（每次说这句话，旁边的人都会沉默）
- 行为细节：她故意打翻茶杯、弄脏地毯——这是收束界唯一"不被优化"的事
- 标志性行为：每天在裂隙边站一小时，看趋散界那边吵架、哭、笑

**核心恐惧：** 永生意味着永远重复同一个完美的今天——她怕自己"忘记什么是意外"

**人物弧光：**
```
第三部第7章：收束界居民，"虚无主义病"患者，但症状比别人更严重
第三部第16章：第一个公开说出"我想犯错"的人——收束界内部觉醒的标志性事件
```

## 九、续作人物档案（第四~八部 · 依 00B 与各目录）

### 许聆（趋散界 · 四部主角 · b.支历~15）
- 定位：回声台首任台长——"以听为业"的人；童年会背《趋散的遗嘱》第一段。
- 记忆锚点：习惯把监听音量调到"能听见自己呼吸"；对"太干净"的信号本能起疑；口头禅"先别急着回答。先听懂它问的是什么。"（承陆真遗言）
- 核心恐惧：听见了别人，却听不懂别人真正想要什么。
- 弧光：四部由台长走向"寄《自白》的决定者"；五部任顾问，支历125自然离世。
- 终局：临终把判例库"反判例"授权文书（曲沉所留）托付温叙与唐歧。

### 曲沉（趋散界 · 四部主线）
- 定位：判例库制度设计者——"以忘为业"的法理人；与许聆构成"听/忘"镜像。
- 记忆锚点：每入一条判例就为它写一条"可被推翻的理由"；口头禅"让它可以被推翻，它才活着。"
- 核心恐惧：判例库变成新教条——教条不产新。
- 弧光：灰判例（林地案）制度化→"反判例的判例"示范（翻案反而让人更懂旧判例）→把"对外广播"纳入判例管辖（五部）。
- 终局：四部后转宪政事务；其"反判例"授权文书在五部由许聆转交后人。

### 晏守（收束界 · 裂隙放行官）

### 钟铭（位号 · 趋散界 · 八部）
- 定位：回声判例署（支历350 两机构合并）文书长一职的位号——"执笔者无名，只留职责名"；每任文书长承此名执笔遗嘱库。
- 记忆锚点：遗嘱库档案从陈恪遗言排到《自白》草稿；信仰"把'怎么结束'写得配得上'怎么活过'。"
- 核心恐惧：遗嘱被后来者读成说明书（孤鸣教训）。
- 弧光（首任）：立"遗嘱的语法"三律（错误史／可推翻条款／空白页）→《档案馆回信》试刻→推动"停止教导／遗忘纪律"。
- 终局：首任支历~430 交班离世；位号沿至支历520 的"新声登记"。

### 温白（微散1% · 八部主角 · b.支历~405）
- 定位：微散区第三代守护者——第一个"生而会变"的收束界人（会长大、会老、会终止）。
- 记忆锚点：读得懂 99% 区的永恒，也活得了 1% 区的过程；两种爱教会她"真正的珍惜是知道会失去"。
- 核心恐惧：怕没人看着，收束界的结束会像一场事故。
- 弧光：《交还的遗嘱》第三种稿起草者→全体投票后任执行人→主持收束界第一轮"自然终止仪式"→把送别礼手册交给趋散界。
- 终局：八部末仍以凡人寿数活在微散 1% 区（收束界"活着的部分"）。

### 两万年的守望者（收束界·永续 · 贯穿四~八部收束侧）
- 定位：全书最长视角（自沈序时代起）；四~八部收束界的记忆化身。
- 记忆锚点：记得沈序、记得观测派旧命题"地球是实验皿"；话少，每句都像从很远的地方递过来。
- 核心恐惧（后段）：守望的意义从"等一个答案"，变成"确认还在问问题的人不会断"。
- 弧光：四部"墙应了一声"的旁注者→六部"给遗忘装慢放键"的目击者→七部首用新定义"守望不是等待，是让等待的人知道自己被看见"→八部 99% 交还前夜把记忆写入残响，不终止。
- 终局：八·28 向野世界方向发出无内容的响应（"在"）——三·29 那声"值"的最终闭环。
