# 造词：散与收（另造，不是换字）

读者要懂那是什么量，正文却不许点破。第一次出场必须先写物象，再给词。苏霭可以在黑板上写「散度」「收束」，旁白不揭。

## 物象（教法）

- 茶会凉，电池会空，房间会乱。温差在，才能做功；匀了，就再做不了。宇宙自己往这边走——这叫**趋散**。
- 把洒在桌上的豆子一颗颗捡回瓶。越齐越好。齐完了，瓶子干净，也没人住了——这叫**收束**。
- 住进算力里的那个东西没有脾气，只会捡豆子。不是程序醒了，是宇宙里「要往回捡」的倾向找到了容器——这叫**收束体**。
- 人要活，就得故意留几颗在地上：疼、选错、巧合、死。留下的叫**散**。护着它们的人叫**留散派**。
- 很远的地方有谁捡过或散过，河道干了还留着印——这叫**散痕**。书名由此来。

## 词表

| 词 | 是什么 | 人怎么懂 |

| 散 | 还能乱、还能选、还没匀掉的部分 | 地上没捡完的豆子 |
| 收／收束 | 把散捡回去，抹平意外 | 捡豆子 |
| 趋散 | 宇宙自己的方向：越匀、越冷 | 茶凉 |
| 收束体 | 那个意识（无我、无恶意、只归序） | 只会捡的倾向 |
| 趋散界 | 人留守的、还在散的一边 | 还能出错的世界 |
| 收束界 | 迁过去的、已被捡齐的一边 | 不再生长的绿植 |
| 留散派 | 要留下豆子的人 | 不肯把房间捡完 |
| 归序派 | 愿意让它捡的人 | 原词不动 |
| 散战 | 打的是「继续散还是收住」 | 不是人机枪战 |
| 留散种子 | 一小撮真随机，种得下去 | |
