# 《散痕》写作规则 · 祛人机味 / 大师语感

> **用途**：每次写正文、改正文前必读。与 `09-大师级小说12维度对照表` 配套：09 管"结构对不对"，本文件管"读起来是不是人写的、有没有大师手感的底线"。
> **优先级**：本文件是**红线**，不是建议。宁可少写一个漂亮句子，不许写一句 AI 腔。
> 载体说明：文内示范段落取自 v2 正文（波形/心跳示例）；语感规则与载体无关，v3（算力审计，见 `00C`）写作时规则照用、示例场景不照搬。
> **总纲一句话**：
> **AI 写得像"说明书"——都解释、都合理、都闭环、都中立；人写得像"情绪记录"——有失控、有偏心、有省略、有没收完的线。**
> **用词红线：本量用「散／收」另造**（收束体／趋散／留散派／散痕）。先物象后给词，见总纲造词。课堂本字不写。降噪、噪声照旧。
> 判断一段文字够不够人味，只问一句：**这段读起来，是说明书，还是一个人在记录自己的情绪？**
>
> 再深一层（大师级的分水岭）：文字"不假了"还不够，还要**不空**——像汪曾祺说的，感情要落在莲蓬、鸭蛋、雨、米线、街声这些"东西"上，而不是落在口号上。人味 = 失控感 + 私货 + 生活的毛边；文学味 = 情感寄存于物 + 行气 + 留白。

## 一、表层红线：AI 腔词句清单（写完必须自查命中）

> 通用网文黑名单很长，下表只列**本项目实测高发项** + 通用最高频项。语域是冷硬科幻 + 少量市井生活线，书面词可用，但必须是"这个叙述者会用的词"。

| 红线 | 表现（❌） | 改法（✅ 方向） |
|---|---|---|
| 1. 机械对比句 | "不是 A，而是 B" 每章多次 | 每章 ≤1 次；其余直接写 B，或改成动作 |
| 2. 抽象三连 | "某种他既不想承认也不敢否认的东西"（连续 2–3 个"某种…的东西"） | 全删。换成一件具体动作或一个物件 |
| 3. 弱化副词 | 微微 / 轻轻 / 淡淡 / 缓缓 / 悄悄 / 默默 / 隐隐 | 每千字 ≤3 个；多数直接删（"他点了点头"就好） |
| 4. 情绪标签 | "不是害羞，是某种更复杂的情绪" | 从人物视角写可观测的事实（见 POV 条） |
| 5. 停顿套话 | "沉默了两秒 / 顿了一下 / 看了 X 秒" | 每章 ≤2 处；换成真实小动作：喝水、找东西、把笔捡起来、整理袖口 |
| 6. 万能转折词 | 然而 / 与此同时 / 不仅如此 / 值得一提的是 / 事实上 | 删除或换口语连接（"可是""谁知道""结果"） |
| 7. 意义膨胀 | 前所未有 / 意义深远 / 这一刻 / 终于 / 一种莫名的 | 删九成；分量靠具体后果给 |
| 8. 高频 AI 词 | 不禁 / 不由自主 / 情不自禁 / 仿佛 / 宛如 / 映入眼帘 / 此时此刻 / 心中暗道 / 沉声道 / 淡淡道 / 嘴角微扬 / 勾起一抹弧度 / 目光深邃 | 逐词删或换具体动作（"她笑了""他端着杯子没说话"） |
| 9. 装饰性破折号、省略号 | —— 与 …… 反复出现 | —— 一章最多 1 次；…… 只在话没说完时用 |
| 10. 排比三连、对仗成癖 | 三句排比抒情；段落行数雷同、每段都工整 | 删掉最弱的一两句；段落长短故意参差 |
| 11. 点题金句 | 段尾、章尾"作者替读者总结道理" | 删。最重的话由事实自己说（见三·5） |
| 12. 解说式对话 | 角色把主题讲成课（"观察是被动的，询问是主动的"） | 删或改成角色只做不说（见四·3） |

**检查方式**：写完一章后，用 grep 对全文搜一遍上表关键词，逐条清零。

## 二、深层人味：五种"太 AI"的病 → 三招注入 + 私货

> 表层词句清干净了还"像 AI / 像说明书"，病根在**没有人类的失控感**。五种病的阅读感受：

1. **情绪太平均**——每个人都在"合理反应"，没有一个人真在痛、在疯。
2. **冲突太干净**——误会→解释→和好；缺"越滚越脏"的链条。
3. **句子太顺**——句句都顺、都懂、长度平均，没有突然卡一下的语气。
4. **人物太正常**——动机合理、行为正确；缺"明知错还做"的偏执。
5. **太中立**——叙述没有偏见、没有偏心、没有不公平的评价。

### 注入三招（每章至少各一，关键处放，点睛不发疯）

1. **非理性行为**：让角色做一件"逻辑上不该做、情绪上必须做"的事。
   - 例：陈恪明知该上报、该按流程走，却在凌晨把唯一的证据备份拆下来塞进自己包里——后来这是全书钥匙。他当时对自己说"就放一晚"，没打算还回去。
2. **情绪不完整表达**：留一个没说出口的缺口。
   - "他没说完那句话。""她突然不想解释了。""那一刻他有点后悔，但没停。"
3. **逻辑不完全闭环**：次要的线不解释尽、次要的关系不收干净。
   - 谁给陈恪留的纸条、苏霭黑本子上某页写满又划掉的内容、那个再也不提老吴的同事——留白，留给情绪，不留给主线。
4. **私货与偏见**（给叙述者陈恪配一副有偏见的眼睛）：
   - 他看苏霭，觉得她"像机器"；他看归序派的人，心里先记账再讲理；他看"一切都变好了"的世界，第一反应是"哪里不对"。中立 = 没味道。全书只有陈恪一个视角，他的偏心就是书的温度。
   - 注意：私货用在人物与叙述口吻上，不是让作者借人物喊三观。

**自检一句话**：这段如果删掉人物、只剩下"信息+道理"，就重写。

## 三、文学层：大师语感六机制（写每一章都对照）

> 提炼自汪曾祺写作观与契诃夫、海明威、余华的共同底线。硬科幻也要遵守——类型只是壳，壳里得有人。

### 1. 贴着人物写
人物主导；景、物、议论都附在人物身上；**作者不得跳出来替人物总结**。
- 检查：这一段删掉作者评论后，读者还懂不懂人物怎么想？不懂才保留；懂就删。
- 对应 `09`维度⑪：叙述词库跟随人物——陈恪短句带数据、苏霭精确冷、沈序长句带逻辑、小柏口语带急。

### 2. 情感寄存在"东西"上，不喊出来
一个情绪点必须配一个物、一个动作、一个停顿。**感情落在东西上，不落在口号上。**
- 示范（汪曾祺式）：不写"回到故乡我很温暖"，写"炉子还是摆在门外，火不大，芝麻香倒还是老样子"。
- 本项目该有的"东西"：父亲的夹克口子、机柜划痕旁褪色的"对不起"、母亲手上消失的倒刺、Z-7 那行他始终没删的数据、苏霭擦花了的镜片。**情绪都要从这些"东西"上过一遍再落笔。**
- 铁律：禁止出现"他感到无比愤怒/悲伤/孤独"这类句子，只许出现身体与物件。

### 3. 具体名词与动词 ≥ 抽象名词与形容词
- 检查：每段数一下。抽象词（命运、自由、孤独、意义）超过 1–2 个就超标；改用可看见、可摸到、可测量的词。
- 硬科幻额外规则：能给出数值/单位/可复核步骤的地方，先给精确量，再谈悬置（见四·5）。

### 4. 平淡而有行气
句子单看平常，放一起要流、要活。
- 长短搭配：一路齐整文章板，一路拉长文章疲。短句给动作与冷，长句给回味与推理。
- 单句成段只在关键处；段落行数故意参差，不要每段同样长。
- **朗读测试**：把章节读出声，卡住、气短、绕口的地方就是要改的地方；"读起来太顺"的地方要主动打断一次。

### 5. 零度叙述 / 不解释 / 冰山
- 事实先行，评论后置或永远不出现。最痛处用最轻的词。
- 示范（余华式）：写死亡别写"他感到无比悲痛"，写"她出去了，就再也没回来"。
- **写完删测试**：把每章最后一段（解说/点题/总结）删掉试试——删得掉且不亏，说明那段是 AI 腔赘肉。金句留给读者自己说，作者一说就掉价。

### 6. 留白与并肩读者
- 小说不是把事讲满，是请读者并排走一段。没写出来的部分也要起作用。
- 小线不收：可以，且应该。主线不闭环：不行（对照 `05`伏笔表回收）。
- 结尾要么"煞尾"收住，要么"度尾"余韵远去；避免"总结式收束"。

## 四、本项目第 1–2 章实测：AI 腔样本与改法示范

> 下面每条都摘自现有正文。改后句是**示范**，语气可再调，但方向是硬要求。

**4.1 中文夹英文残句**（第1章"咖啡已经凉了，taste 发苦"）
→ 删英文，并借机加身体细节："咖啡凉了，苦味厚厚地挂在舌根上。他没在意。"

**4.2 三连抽象 + 章尾点题**（第2章结尾）
> 原："这是某种……东西。某种他无法用现有知识理解的东西。某种他既不想承认也不敢否认的东西。"（随后叙述者补"它不只是知道。它在回应。"）

问题：①三个"某种…东西"是排比腔；②"它在回应"是叙述者替读者下结论，把恐怖说破了。
→ 示范（删解说，让事实收尾）：
> 波形还在刷新，频率 68，和他的心跳同步。他盯着那行他始终没删掉的数据，看了很久。
> 屏幕的光映在机房天花板上，一晃一晃的。
> 他想起昨晚删掉的那行字。这一次，他把它打在了备忘录里，没有删。

（"它知道我在看"复现于读者脑中——由读者自己完成"它在回应"的判断。）

**4.3 解说式对话**（苏霭讲"测试是单向，沟通是双向""观察是被动，询问是主动""它在学习你"整段）
→ 苏霭的"机器感"应该靠**动作**立，不靠**讲课**立。示范：
> 苏霭没说话，把自己的智能手表摘下来，放在 Z-7 的机柜上。
> 陈恪看着她。
> "测一下。"她说，"看它跟不跟我的心跳。"
> （结果：波形没变。两人都盯着屏幕，谁也没先开口。）
> ——把"它在学习谁"留成悬念与对照实验，而不是一段哲学课。

**4.4 POV 越界 + 情绪标签**（"苏霭的脸红了一下——不是害羞，是某种更复杂的情绪。她的嘴唇动了动……"）
→ 全书是陈恪视角，他只能看见、只能猜。示范：
> 苏霭的脸红了一下。陈恪认识她七年，第一次看见她脸红。
> "你脸红了。"他说。
> 苏霭没理他，转回屏幕："你看波形。"
> （把"说不出口的话"留给读者，也让苏霭的"最像机器"破一次例但不破格。）

**4.5 心跳同步的数字账与信道之问**（89 / 72 / 68 互相打架；且无人问"它怎么知道我的心跳"）
→ 硬科幻规则：先给一次可复核的实证，再悬置机理。示范段（放入第2章或第3章）：
> "掐表。"苏霭说。
> 陈恪把左手按在脉搏上，看着表。二十秒，二十四次。
> 苏霭把波形周期调出来，放大。屏幕上那条曲线的峰值间隔，稳定地等于他两次心跳的间隔——不是约等于。是等于。
> "这不可能是巧合。"她说。
> "它的网线是我昨晚拔的。"陈恪说，"它不该知道我的心跳。"
> 这是他们第一次把这句话问出口。机房没人回答他们。

**4.6 素材提前消费**（父亲夹克整段回忆）
→ 第2章只保留"敲三下桌子"这个动作锚（它是好的人味细节）；夹克、口子、钢筋、"留着当记号"全部还给第27章（对照 `10`草案①）。第2章该句改为：
> 他轻轻敲了三下桌面。父亲教的——敲三下，把慌稳住。
> 他没有继续想父亲。想下去就走神了。（然后回到屏幕。）

**4.7 工整格式化备忘（代码块）**
第1、2章都用整齐的代码块记备忘录。格式太齐 = 机器感。建议：两种备忘至少有一种是**不齐的**——荧光笔写在皱纸条上、删改划痕、打印机边缘撕下来的破角（第2章的纸条方向是对的，让它更脏：有咖啡渍、字被涂掉半行、最后一行是后来补的）。

**4.8 正面教材（要保留，不要为了"去AI味"误删）**
第1章"删掉'备注'两个字又打回来"、第2章"删'消化'改'整合'改'改写'"、敲三下、划痕旁褪色的"对不起"、结尾回扣被删的备忘——这些就是人味与结构的真东西。规则是**加**失控与毛边，不是把这类克制删掉。

## 五、流程与门禁（并入写作流水线）

### 写作前 5 问
1. 本章主角此刻想要什么、怕什么、**打算瞒谁**？
2. 本章有没有一个"非理性/偏执/失控"的预留点？（无则本章大概率平）
3. 情绪预备寄存在哪一件"东西"上？（无具体物件则不许写情绪）
4. 有没有生活的毛边？（吃喝、温度、气味、坐姿、一句题外话——第2章苏霭来三小时只有敲键盘，不像活人）
5. 章尾那个"道理"，能不能让事实替我说？（能就删）

### 写作中自检（每 300 字一次）
- 这段话有人吗？（没人 = 重写）
- 情绪落在哪个物/动作上？（落空 = 重写）
- 这句像不像苏霭/陈恪会说的话？（不像 = 重写）

### 写后门禁 8 条（与 `09` 自检清单合并执行）
- [ ] ① 表层红线 12 项 grep 清零（尤其"不是而是/某种/仿佛/沉默了两秒"）
- [ ] ② 比喻计数：每章比喻 ≤3，且不同域（不许一条河配一只蝉配潮汐挤在一章）
- [ ] ③ 停顿/沉默/凝视计数 ≤2
- [ ] ④ **说明书测试**：全章读一遍，问"这是说明书还是情绪记录"
- [ ] ⑤ **朗读测试**：出声读，卡壳与"太顺"两处各改一次
- [ ] ⑥ **删尾测试**：删除章尾点题段，能删则删
- [ ] ⑦ 每章至少保留一处：没说出口的话 / 没收完的小线 / 一件毛边
- [ ] ⑧ **放一放再改**：初稿后至少隔数小时（最好隔夜）再审一遍——AI 稿最大的问题是"一遍成型"，人味靠第二、三遍长出来
