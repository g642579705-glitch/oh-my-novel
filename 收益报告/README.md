# 收益报告

本目录存放每期《收益报告》。分配规则见 [CONTRIBUTING.md](../CONTRIBUTING.md) 第 4 节。

**当前状态：尚无收入。** 首笔收入到账后 60 天内发布第 1 期。

## 报告格式

每期一个文件，命名 `YYYY-QN.md`（如 `2027-Q1.md`），内容固定为五段：

1. **收入**：日期、来源（打赏 / 赞助 / 出版 / 授权 / 周边）、金额、币种。
2. **支出**：平台抽成、支付手续费、税费、直接成本，逐条附凭证说明。
3. **分配池**：收入 − 支出。
4. **贡献分**：本周期贡献清单（人名 / 类别 / 贡献分），可链接到清单 Issue。
5. **份额**：每人应得金额 = 分配池 × 个人贡献分 ÷ 全体贡献分；注明已发放 / 待认领。

## 约定

- 报告发布后 7 天内可在对应 Issue 提出异议，逾期视为确认。
- 报告一经发布不修改金额，更正以"补充说明"追加，保留原文。
- 个人收款信息不入库，只公示 handle 与金额。
