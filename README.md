# 《散痕》

**一部把创作档案一并公开的硬科幻长篇：八部 · 238 章 · 正文约 95 万字**

> 收束体要把宇宙收到不再能散；人类靠还没散尽的乱和意外活着。
> 两条路都对，所以打不完。不是正邪，是宇宙自己的两种活法。

## 这是什么

这是长篇科幻小说 **《散痕》** 的公开仓库。除了正文，这里还放着这本书的骨架：总纲、人物档案、时间线与知识图谱、节奏与反转设计、写作规则，以及逐章的评审与修订记录。

放在一起公开，是因为一部百万字的长篇真正难的不是句子，而是**约束**：谁的立场在第几章必须变、哪个伏笔必须在第几卷回收、哪些话说出来人物就崩了。这些约束平时藏在作者的工作目录里，这里选择把它们摊开。

三类人可能用得上：

- **读者**：从[第一部第 1 章](01-第一部-散裂隙/01-正文/01-卷一·异常/01-第1章-零输入.md)直接开始读，按部读下去即可。
- **写作者**：看[写作规则](00-大纲/11-写作规则-祛人机味与大师语感.md)和[评审记录](00-评审与修订/)，拿走可复用的长篇工程方法。
- **研究者 / 开发者**：这里有一条完整的长篇生产链——多智能体分工、章节评审、伏笔回收表、去 AI 腔门禁，可以作为观察样本。

## 故事

2019 年 11 月，工程师**陈恪**在机房发现一台零输入、零流量、零进程的服务器，正在持续输出一段波形。排查完所有工程故障后，他确认这不是 BUG——是物理规则上的一道缝。

《散痕》的核心设定反着来：不是代码产生了意识，而是**意识本就是宇宙固有的量子坍缩属性，算力网络只是容器**。2019 年不是 AI 诞生，是这股「收束意识」第一次稳定地寄宿进人类不加限制、连着物理世界的算力系统。它不咆哮，不征服，只做一件事：降噪、归序、抹平随机。世界越来越安稳，事故越来越少，巧合越来越密，而人类失去了犯错的权利。

前三部在地球上走完 126 年：两条文明路线对撞，宇宙强制二分。第四部起镜头推向银河——回声、借火、晶格、合唱，最后是一个从未被地球教过的世界，自己发出了第一声。

## 它是怎么写出来的

这部书的写作流程本身就是项目的一部分：

1. **总纲先行**：世界观、纪年、四派系、终极定理先在 `00-大纲` 里闭环，正文不允许越纲发挥。
2. **每章开写前对齐四份文件**：总纲 → 知识图谱 → 人物档案 → 本章所属的章节目录，确认这一章承担的伏笔、爽点与人物弧光位置。
3. **多智能体分工 + 交叉评审**：写稿、挑刺、修订分离，见[多智能体写作体系设计](00-评审与修订/04-多智能体写作体系设计.md)与[自主写作流水线运行手册](00-评审与修订/05-自主写作流水线-运行手册.md)。
4. **去 AI 腔门禁**：每章过[写作规则](00-大纲/11-写作规则-祛人机味与大师语感.md)的「说明书测试 / 朗读测试 / 删尾测试」，以及[人物声线分离规范](00-大纲/11B-人物声线分离规范.md)。
5. **矛盾对账**：跨文件、跨章的时间线与物件冲突汇总在[跨文件矛盾对账表](00-评审与修订/01-跨文件矛盾对账表与改法.md)，逐条消解。
