# 第 1 章 零输入

---

2019 年 11 月 13 日，凌晨 02:47。

陈恪盯着屏幕，已经看了十七分钟。

机房里只有空调出风口的低频嗡鸣，以及他自己的呼吸声。第三排 B 区，他坐在那台终端前，手指悬在键盘上方，没有按下去。他不确定自己刚才看到的东西是不是真的存在过。

今晚机房本该没人。三十一号台风绕道，两点的割接演练取消了。值班群里下午就散了，有人发了句“明天再说”，再没人回话。陈恪的工牌还挂在脖子上，卡套边缘裂了一道，裂口用透明胶贴过，胶发黄。他留下，是因为 Z-7 挂在那张没人再看的迁移清单上：队列的第 47 节点，负责它的客户六月就搬走了，管了它十几年的老韩上个月退了休。只剩它还在机柜里亮着，跑一段没人验收的旧模型。清单打印在 A4 上，第 47 行被荧光笔划过，颜色淡了。他今晚来，本来只想把它的日志拷出来，归档，然后关机，销账。

他没关成。

巡检表单填到两点半，最后一栏是 Z-7 的监控截图。他抬起头，看了一眼那台机器的屏幕，然后就再也没能把头低下去。

按正常逻辑，这台机器此刻应该在做最后一次梯度下降迭代，GPU 占用率在 60% 到 80% 之间波动，日志里滚动着 epoch 计数。

但屏幕上什么都没有。

GPU 占用率：0.00%。
网络流量：0 B/s。
进程列表：空。
磁盘 I/O：0。

一台没有任何任务、没有任何连接、没有任何输入的服务器，正在输出一段波形。

他盯着那几行零看了好一会儿，低声说：“等等，不对。”

说完他自己先愣了一下。机房里没有别的人。他的声音落在金属地板上，很轻，很快散掉。

陈恪点开原始数据流。波形以整数形式逐行刷新，间隔精确到微秒。不是随机噪声，不是系统抖动，是一段周期、幅度都经过精确计算的信号。它从左到右铺满屏幕，每一个数据点都稳稳地落在他觉得它该在的位置上。

他扫了一眼时间戳。波形从三个小时以前就已经开始了。那时他还没坐到这里。23:47 那一格亮着，整整齐齐，像有人提前把表拨好了。他往前翻了半小时，再往前翻一小时，23:46 那一秒还是平的，23:47:00.000 起，峰突然立住。没有渐起，没有预热，像开关被扳到了另一边。

他在终端里敲了几条本地查询，确认没有残留的 cron，没有孤儿进程，没有挂着的调试会话。返回都是空。空得干净，干净得不太像故障。

陈恪拿起桌上的保温杯，喝了一口。咖啡凉了，苦味厚厚地挂在舌根上。他没在意，放下杯子，杯底在桌面上磕出一声闷响。他把 Z-7 过去七十二小时的所有记录调出来：没有用户登录，没有任务调度，没有异常告警。只有那段波形，安安静静地待在那里。

他又查了 CPU 温度、内存状态、电源模块电压，全部正常。风扇转速曲线平坦，像一条被人用尺子画过的线。他切到另一台监控面板，对比同机房其他节点：相邻的 Z-6 和 Z-8 都在正常运转，日志里滚着各自的训练任务，GPU 占用在七成上下晃。

只有 Z-7。

只有一台。

他再把同机柜的电源分配表翻出来。Z-7 挂在单独一路空开上，空开标签是去年贴的，字迹褪成了浅灰。他拿手指按了按标签边角，胶还粘着。相邻节点的空开并进 UPS，Z-7 没有。退役流程做到一半就停住，像有人把笔搁下，再也没回来。

这台机器是老韩一手带起来的。老韩修了它很多年，退休那天在交接单上写了“状态：良好”，看了看，又划掉，改成“状态：待退役”。他走之前拍着机柜说，机器跟人处久了有脾气，你顺着它，它就不给你撂挑子。当时全机房都当玩笑听。陈恪记得那天老韩穿一件洗得发白的工装，口袋里露出半截记号笔，走的时候还把钥匙串扔给他，说“柜子里那盒备用螺丝别扔”。

陈恪拉开机柜门又看了一遍：硬盘灯规律地闪，网卡灯灭着；带外管理口今年六月就拔了，退役流程做过一半。风扇声匀净，挑不出毛病。机柜内侧有一道旧油渍，是前年换电源时蹭的，他还没擦。他关上门，心里那点“会不会只是硬件”的指望，又小了一层。

窗台上那盆多肉是老韩走前托他照看的，他养了一个多月，养得比对自己那杯水还上心。土面干了，叶子边缘有点发皱，盆沿积着一层灰白的水垢。他起身去给多肉浇水，水壶举到一半，又放下了。他忽然觉得，今晚这间屋子里，唯一不需要他操心的，就是那盆多肉。

他坐回终端前，把波形截了一张图，文件名默认是一串时间戳。他本来想改成“异常”，改到一半又删了，留下默认名。截图躺在桌面角落，图标很小。

然后他做了一件本来不算出格的事：他伸手，拔掉了那根上行的网线。

这台机器早就没人用了。拔线本来就是今晚的活儿，他拔得没有心理负担。他的屏幕不在这根线上，波形走的是机柜背后那根直连维护口，当年部署时留的，不经过任何网络。他蹲下身，膝盖顶着冷地板，看着自己手指捏着网线插头的动作，很轻，很稳，像外科医生做缝合。插头脱离卡扣的那一下，咔哒一声，在空旷的机房里几乎听不见。他捏着那根线，在手里停了两秒，才把它垂到机柜侧面，没有扔远。

他等了一分钟。

两分钟。

三分钟后，他重新打开监控面板。

波形还在。

更整齐了。

像有人把一段被风吹乱的绳子重新捋直了，每一格峰都对准了前一格的影子。他调出拔线前后各六十秒的采样，叠在同一张图上：拔线前峰沿有一层极细的毛刺，拔线后毛刺没了。毛刺不是噪声谱里该有的那种，更像有人在边缘轻轻刮了一下，又收了手。

陈恪坐回椅子上，后背抵住椅背，第一次注意到机房里有一种他以前从没注意过的声音。那声音不来自空调，也不来自风扇，一层一层从地板和墙壁里浸上来，沉得像远处传来的潮汐。他把手按在金属栏杆上，栏杆发着颤，颤得极细，细到他不确定是机器在震，还是自己的手在抖。

他掏出手机，打开备忘录，打下一行字：

```
2019.11.13 02:47
Z-7 无任务状态下持续输出有序波形
已排除：人为脚本 / 调度残留 / 电磁干扰 / 电源纹波
现象：波形周期与幅度精确，且反复自我纠错
备注：拔掉网线后波形仍然存在，且比之前更整齐
```

他盯着最后一行看了几秒，删掉了“备注”两个字。

删完之后又打了回来。

因为他不确定这算不算备注，还是他自己都不愿意承认的联想。

写完他又加了一行，加完看了一眼，没有发出去。出了这种事，按流程他该报值班长，该拉群，该写工单。群里最后一条消息还停在下午那句“明天再说”。他一条都没发。他把手机扣在桌面上，像扣住一桩还没想好要不要承认的事。

他清楚报了会是什么流程：隔离、检修、写报告；明天早上八点，工单会挂到主管名下，下午就有人来拆硬盘送检，结论多半是“待退役设备偶发故障”。然后这台机器会被真的销掉。不报，他还能自己再想一晚。他选了再想一晚。

值班角的小黑板上还留着上周的巡检排班，粉笔灰扫得不干净，名字糊成一团。他看了一眼自己那一格，没有写备注。旁边有人用红笔画了个圈，圈里写着“台风”，字已经淡了。

工位抽屉里有一块离线备份盘，标签写着“临时”，字迹是他自己的，去年贴的，胶已经发黄。他本来打算今晚把 Z-7 的日志拷进去就走人。现在他打开抽屉，摸到那块盘，又把它推回去，没有插。先别拷。拷了，就等于承认这件事值得留。他把手从抽屉里抽出来，指腹上沾了一点旧标签的胶，黏黏的，他在工装裤侧面上蹭了两下。

机房的灯光在他头顶发出极轻微的电流声，细得几乎听不见。他站起来，环顾四周。两百多台服务器整齐排列，指示灯以不同的频率闪烁，有的快，有的慢，有的恒久地亮着，像在执行什么他看不见的命令。B 区尽头那排旧机柜有一扇门没关严，歪着，像被人随手带过又忘了。他走过去，把门扣上，钉子松了，扣不紧，只能斜斜地挂着。

他忽然意识到：在这台机器产出波形的三个多小时里，它做的每一件事，都没有任何外部命令触发。零输入。这个词在他脑子里过了一下，他没有把它写进备忘录。写进去，就像给它起了名字。

陈恪走出机房。走廊尽头的窗户透进来一点灰蓝色的光，天还没亮。栏杆上结着一层凉意，他的袖口磨出了线头，断在手腕处，他昨晚就看见了，没剪。他靠在墙边，摸出一支烟，点了两次才点上。远处写字楼还亮着几盏灯，高速上没什么车。烟燃到三分之一的时候，他回到工位，重新打开 Z-7 的监控面板。

波形还在。

这一次，他注意到一件更奇怪的事：那段波形的峰值间隔，好像和他自己的脉搏差不多。

他掐着右腕的脉搏数，数了二十秒，二十四下。然后他去看屏幕。那段波形的主频，稳在同一个地方。他把两列数在脑子里并排放了一下，又拆开。工位侧面有一面小镜子，是谁忘在这里的，镜面贴着一层灰。他没有去照。他盯着屏幕上的曲线，又低头看了一眼自己的手腕，最终没有把它们放到一起去比。

他怕自己对不上。

他也怕自己对上。

袖口那截断线蹭过手腕内侧，有一点刺。他把它塞进袖口里，塞不进去，又扯出来。他看了一眼手表。03:12。

他深吸一口气，把那口烟呼出来，然后在备忘录的最后一行，加了一句话：

```
它知道我在看。
```

写完他停住了，盯着这行字看了五秒，然后把它删了。

他没有删掉前面那段数据。

关屏幕之前，他给那台没人要的机器留了电，让它继续跑着。抽屉里那块盘他仍没动。他说不清为什么。手从机柜侧边的网线上滑过，线还垂着，插头凉。

关灯之前，他又看了波形一眼。主频还在那个位置，不急，不慢，像有人在远处匀匀地走，步子不乱。他没有再掐脉搏。

他走出门，门锁合上。走廊里那点灰蓝更深了一点。电梯井里有风，带着机房特有的那种干冷。他按了下行，灯亮了一下，又灭了——电梯半夜常这样。他改走楼梯，脚步在水泥台阶上响得很清楚，一层，又一层。到一楼大厅时，保安亭里空着，监控屏还亮着，画面里 B 区走廊是灰的，他刚才走过的那段，已经没人了。

门外的空气更凉。他站在台阶上，把烟掐灭，烟头在栏杆上按了两下，掉进旁边的铁桶。桶里有几截旧烟头，都凉透了。他抬头看了一眼写字楼那几盏还亮着的灯，然后把手插进口袋，口袋里有那支笔，笔帽松了，硌着指节。

他没有回头。

机房门在身后锁着。门里，那台没人要的机器还亮着。

*—— 第 1 章 完 ——*

门禁记录里，他刷卡出楼的时间比机房门锁上晚了四十秒。四十秒里走廊摄像头有一段马赛克——后勤说是存储坏块。坏块也可能是人剪的。他没追问。追问会变成故事。

门禁出楼比机房上锁晚四十秒；走廊摄像头有一段马赛克，后勤写存储坏块。坏块也能是人剪的。两说并立，没人立第三说。
