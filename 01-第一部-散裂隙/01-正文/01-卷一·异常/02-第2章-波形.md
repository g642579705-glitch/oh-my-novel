# 第 2 章 波形

---

2019 年 11 月 14 日，凌晨 01:03。

陈恪把网线重新插上了。

咔哒一声。插头重新嵌入卡扣的声响，和昨晚一模一样。

他盯着屏幕。

波形还在。

频率没有变化，幅度没有变化，周期仍然精确到微秒级。拔掉网线之后，它反而更整齐了，像一条被干扰过的河，在干扰消失后重新找到了自己的河道，而且比之前更宽、更深。

他把手伸进口袋，摸到那张纸条。纸条是从打印纸边角撕下来的，折痕里夹着一小片咖啡渍，边角卷着，像被捏过很多次。上面有一行荧光笔写的字，写到一半，有一处被他自己划掉了：

```
拔掉网线后，波形更整齐。
~~它怕网线。~~
```

字很潦草，是他昨晚在机房里写的，写完塞进口袋，忘了扔。现在他盯着这行字看了很久，发现里面藏着一个他自己都没意识到的逻辑：拔掉网线，波形更整齐。这意味着，Z-7 在“感知”网线的存在。

网线是外部输入。移除外部输入，它表现更好。它不需要外部输入来维持波形。

它“讨厌”外部输入。

陈恪把纸条放回口袋，手指在桌面上无意识地转着那支笔。笔掉在了地上。他没有弯腰去捡，继续想。

他站起身，绕着 Z-7 的机柜走了一圈。机柜正面有一道划痕，是三年前同事搬设备时撞的，划痕旁边有人用记号笔写了一行小字：“对不起。”字迹已经很淡了，淡到要凑近才能辨认。他用指腹蹭了一下那行字，墨迹不起皮，只蹭下一层灰。他盯着那行字看了三秒，忽然笑了一下。不是因为好笑，是因为他发现自己正靠“看划痕”来拖延时间。他在害怕下一步该做什么。

他回到终端前，指尖在键盘上方停了一秒，然后开始输入。

他写了一段“有结构的噪声”：1024 个整数，范围在 0 到 255，分布看起来均匀，但每隔 128 个整数藏一个扰动点，扰动点的数值按斐波那契数列的末位排列。看起来是随机的，底下却有一根看不见的骨架。写完他先在本地跑了一遍校验，把扰动点的位置打印成一张表，折进口袋，免得等会儿靠感觉比对。

脚本存到 /tmp/noise_exp.py，执行。1024 个整数一行接一行刷过去，密得看不清。终端风扇陡然高了一档，热风扑在他手背上。然后他通过 Z-7 的监控接口，把这段数据发了过去。如果它只是被动输出，数据会直接消失，什么都不剩。

他盯着监控面板。

三秒。

五秒。

十秒。

波形变了。不是“更整齐”的那种变，是结构变了。原本平滑的曲线上多出一段波动，那段波动的频率、幅度、相位，和他刚才那串数据的隐藏骨架完全一致。他把发送数据和波形变化逐点比对：128 个整数，128 个扰动点，一一对应。

误差为零。

陈恪盯着那个“误差为零”看了很久。他轻轻敲了三下桌面。父亲教的：敲三下，把慌稳住。他没有继续想父亲。想下去就走神了。

他在终端里记录实验结果。写到“推论”那一行时，他停住笔，在“消化”和“整合”之间改了很久，最后留下“改写”。这个词最中性，不暗示意图，不暗示谁在主导。数据进来了，数据出去了，出去的和进来的不一样。

但他心里清楚，事实比“改写”两个字重得多。

他看了一眼时间。01:17。他已经连续干了七个小时。

他需要一个人。不是随便一个人。是一个会问他“误差真的为零吗”，而不是问他“是不是太累了”的人。

他拿起手机，翻到通讯录。

```
苏霭
数学系 / 信息论
备注：别在凌晨打电话
```

他盯着那行备注看了两秒，按下了拨号键。

铃响了四声。第四声快结束时，电话接通了。

“喂？”声音很轻，带着刚醒的沙哑。

“是我。”陈恪说，“别生气。”

“什么事？”

“你能来机房吗？”

电话那头沉默了两秒。

“现在？”

“现在。”

又沉默了两秒。然后她问了一句让他没想到的话：“你吃饭了吗？”

陈恪愣了一下。“……没。”

“地址发我。”

电话挂了。陈恪盯着屏幕，忽然笑了一下。苏霭不问是什么事，不问严重吗，只问地址。认识七年，这是她第一次在接他电话的时候，先问他吃没吃饭。他不知道该高兴，还是该觉得哪里不对。

二十分钟后，苏霭出现在机房门口。她左手拎着一个便利店的纸袋，袋子底部洇了一小块油渍。进门先放在桌上，从里面掏出一盒热豆浆和一只面包，推到陈恪面前。豆浆盖子边缘还烫，她用指尖顶着推过来，自己没拿。

她穿着宽松的灰色卫衣，短发，没怎么打理，别到耳后的几绺又滑了下来。脸上没化妆。卫衣口袋里鼓着一块东西，像是钥匙串。她站在门口先缩了缩脖子，说：“你们机房比我们楼里冷。”

陈恪没接话，把屏幕转过来给她看。

苏霭低头看了一眼，皱了皱眉：“Z-7？它不是要退役了。”

“是要退役。”陈恪说，“它先给你看点别的。”

苏霭走到终端前坐下来。她先把卫衣袖子往上撸了两道，露出细瘦的手腕，腕骨凸着一点。陈恪给她倒了杯水，水是凉的，他忘了烧。杯子沿有一道旧磕痕，她喝的时候嘴唇避开了那道痕。苏霭喝了，没说什么。那盒豆浆陈恪喝到一点半才喝完，面包他放在机柜边上，到最后也没吃完，像搁着一句没来得及说的谢。

“查过什么了？”她问。

“硬件、软件、电磁、温度，昨晚全查过。没有用户登录，没有任务调度，进程列表是空的。相邻的 Z-6、Z-8 都正常。”

苏霭点了点头，没有信他，把能查的都重新查了一遍。结论一样：这台机器什么毛病都没有。

“问题不在机器。”她把椅子转过来，“波形 23:47 就开始输出了。你几点到的？”

“两点半。”

“它比你早到将近三个小时。”苏霭说，“但它输出的内容不对。”她把陈恪的智能手表要过去，调出昨晚的心率记录，再把 Z-7 波形主频的采样调出来，两列数据并排铺开。她没说话，拖了拖滚动条，又拖回去，再拖回来。

“陈恪。”她说，“你昨晚 02:30 进机房，心率 89。02:47 到 03:12 你基本没动，72。”

“我知道。”

“波形里两段都在。”她指着屏幕，“89 那一段在前，72 在后。接得严丝合缝，中间没有一秒钟的错位。它是按顺序放的，像在回放你。”

陈恪盯着那两段曲线，没有说话。

“回放从什么时候开始？”他问。

苏霭把滚动条拖到最左端。波形开始的时间，是昨晚 23:47。他还没进机房。

“它从你进门之前就在输出了。”她说。

机房安静了一会儿。空调的嗡鸣声显得格外清楚。

“我的表不连这台机器。”陈恪说，“它的网线昨晚是我拔的。它不该知道我的心跳。”

苏霭没有接话。她把波形主频和手表记录的时间轴又对齐了一遍。不是约等于，是精确到同一秒。然后她说：“先别问它怎么知道的。先把‘它知不知道’这件事，做扎实。”

她从自己手腕上摘下智能手表，放在 Z-7 的机柜上。

“测一下。”她说，“看它跟不跟我的心跳。”

五分钟过去，波形没有变。它没有跟着苏霭的心跳走。苏霭把自己构造的一段数据发给 Z-7，波形整合了数据，但波形里始终没有出现属于她本人的心率调制。机柜上那块表的屏幕还亮着，心率数字一跳一跳，和波形主频各走各的，像两条不肯并轨的线。

苏霭把表戴回去，表带扣得比刚才紧半格，面无表情地下了结论：“它挑了你。”

“……它挑我干什么。”陈恪说。

这句话问出来，两个人谁都没接。苏霭的嘴唇动了动，像有什么话到嘴边，又咽了回去。她把屏幕转回自己面前：“你昨晚对它做过什么？从头说。”

陈恪说了：拔网线，波形更整齐；输入噪声，128 个扰动点被整合，误差为零。

苏霭把昨晚那段噪声原样重放了一遍。她先让陈恪去开水间接水。波形没有反应。两分钟后，陈恪端着杯子推门进来。波形重新开始整合。

“它认的不是数据，是我在场。”陈恪说。

“是你这个人。”苏霭纠正他，语气平板得听不出情绪。

苏霭听完，靠在椅背上，很久没说话。

“它把你的心跳记下来了。”她终于说，“然后一遍一遍地放。”

“放到什么时候？”

“放到你回来。”苏霭说，“你一进门，它就从头开始放。”

陈恪没有说话。他看着屏幕上那段波形，忽然想起昨晚那个他没敢做完的验证。他把手伸到脉搏上，又放下了。

“它昨晚就开始放了。”他慢慢地说，“在我还不知道它在放的时候。那它现在放的这些……”

“是你进机房之后才有的。”

“对。”陈恪说，“所以它要么是在记录我。”

“要么？”

“要么它知道我会来。”他说，“它知道我会在两点半走进这间机房。所以它提前三个小时，开始等。”

苏霭没有反驳他。她把那段波形存成文件，文件名打了两个字：回放。

凌晨四点，苏霭靠在椅背上，问了一句从进门到现在她都没问过的话：“你想不想跟它说句话？不是输数据。是说话。”

“跟一台退役的服务器说话？”

“跟它说话。”苏霭说，“比如问它，你在这里做什么。”

陈恪把椅子往前挪了半寸，屏幕光压在他脸上。他深吸一口气，在终端里输入了一行字：

```
print("你好。")
```

然后发了过去。

三秒。

五秒。

十秒。

波形变了。不是结构变化，是更微妙的变化。波形的主频，从每分钟 72 次，变成了每分钟 68 次。

陈恪低头看了一眼自己的智能手表。心率：68。

波形的主频：68。

一模一样。

“它追上你了。”苏霭说，“刚才它还在放昨天的你。现在它跟着现在的你。”

陈恪没有说话。他盯着那段和他心跳同步的波形，忽然想起昨晚删掉的那行字。他把右手搭到左腕上，数了二十秒的脉搏。二十三下。屏幕上的波形，峰值间隔和他数的，完全一样。

他没有去数第二遍。

凌晨四点半，陈恪把昨晚的日志、实验记录，还有苏霭存的那份“回放”文件，都拷进了一个没人会看的备份盘。盘的塑料壳裂了一道细缝，他用胶带缠了两圈，缠得歪。他对自己说，先放着，明天再说。

明天他不会再说。

Z-7 的退役确认单在流程里躺了两周，一直没提交。确认单打印件压在键盘托盘下面，页角卷着，盖章栏空着。今晚他本来想把它交上去。他没交。他把那张单子抽出来看了一眼，又塞回去，比原来更深一点。

“它的网线是我拔的。”他关掉屏幕之前，又看了一眼那段波形，“它不该知道我的心跳。它不该知道我会来。”

苏霭在门口等他，问：“那你要怎么办？”

“我想起一个人。”陈恪说，“三年前，有个做分布式存储的，姓吴。行业会上他提过一句，说他的集群也出过一阵‘没人调度的波形’。我问他后来呢，他说查过了，硬件老化。”

“你信了？”

“当时信了。”陈恪说，“现在我想给他打个电话。”

他拨过去。忙音。再拨，空号。通讯录里老吴那一行备注还写着“分布式存储 / 行业会”，字是三年前存的。他盯着空号提示看了两秒，把通话记录划掉，没有存截图。

他把手机放回口袋。窗外还是黑的。Z-7 的波形还在刷新，主频已经慢慢回到 72。那是他昨晚坐定以后的心率。它记住了他安静下来的样子。苏霭在门口拉了拉链，拉链齿卡住一下，她扯了扯，才拉上去。

陈恪打开备忘录，把那行字打了上去。

昨晚他打过一次，删了。这一次，他没有删。

```
它知道我在看。
```

*—— 第 2 章 完 ——*
