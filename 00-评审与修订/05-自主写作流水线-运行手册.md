# 《散痕》自主写作流水线 · 运行手册（无人值守版）

> 状态：自主运行（作者不参与）。替代 `04` 中依赖人类的门禁：作者终审点改为"机器双审 + 门禁达标 + 细节缺口由细节银行代生成并标记"。
> 目标：第一部《散·裂隙》28 章全部正文 → 发版级（发布标准见下）。
> 运行机制：本仓库由长期目标驱动（每轮推进数章）；所有共享状态落在 `00-写作运行/`，正典文件只读。

---

## 一、自主角色集（精简，9 个 AI）

| 角色 | 职责 | 出现时机 |
|---|---|---|
| E1 执行主编 | 装配每章指令包、汇总评审、裁定修订清单、维护章节状态 | 每章 |
| W1 主笔 | 唯一落笔者；先写后两轮自改（删解说→加人味） | 每章 |
| W2 备稿 | 场景备选/扩写方向（卡壳时） | 按需 |
| W3 细节银行 | 生成"有生活底子的细节/毛边/记忆碎片"填补素材缺口，统一打标 `[待作者复核]` | 缺口出现时 |
| R1 设定对账官 | 对账 04/05/06/07/08+章节目录+F表；更新账本 | 每章 |
| R3 红线质检 | 11 号规则 12 条表层清零 + 门禁 8 条 | 每章 |
| R4 硬核考据 | 物理/信道/数值/年代硬伤 | 每章或隔章 |
| R6 共情读者 | 人味：情绪标签/工具人/毛边/失控点/主题说破 | 每章或隔章 |
| S1 卷末复盘 | 09 十二维打分 → 下卷写作指令 | 卷末 |

## 二、每章周期（无人值守闭环）

```
1. E1 装配指令包（写盘 00-写作运行/当前章包.md）
2. W1 初稿（按指令包+前章接口+11号规则）→ 自改一轮（删解说/删尾）→ 入稿
3. R1+R3+R4 并行评审（各自读 稿+相关正典）→ 结构化报告（证据+改法）
4. R6 人味评审（读稿）→ 报告
5. E1 汇总 → 修订清单（只收带证据项）→ W1 修订稿
6. 复检：R3 门禁 8 条 + R1 对账零冲突 → 定稿
7. 账本更新：埋点回收/时间轴/人物弧光位置/惊奇预算
8. 写"下一章接口"（末段状态+钩子+待决）→ 归档 → 返回 1
```

## 三、发布标准（发版级 = 全过）

- [ ] 11 号规则：表层 12 项 grep 清零；门禁 8 条过（含说明书/朗读/删尾）
- [ ] R1：与大刚/F 表零冲突；章节状态与账本已更新
- [ ] R4：无物理/信道/数值/年代硬伤（含心跳账、时间线、人物年龄）
- [ ] R6：每章 ≥1 失控点/没说出口的话/毛边；无解说式点题、无 POV 越界
- [ ] 惊奇预算表：本章占位唯一，未透支后续章
- [ ] 字数：**不设单章/卷下限或上限**；以场景与选择完整为准，禁止为凑字加厚或段内复读
- [ ] 情绪类型与本卷曲线一致，与前后章不同
- [ ] 至少两轮评审意见有记录且闭环（00-写作运行/评审记录.md）
